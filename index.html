AI Resume Screener

Python · Flask · spaCy · scikit-learn

A web app that scores uploaded resumes against a job description. It combines TF-IDF cosine similarity with skill-overlap matching, then reports a match score, the skills that matched, and the specific skills missing from each resume. Uploads are parsed per file so one bad document does not break the batch.
