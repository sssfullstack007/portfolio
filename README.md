# Portfolio

Personal portfolio page for Sai Srinivas Shella — ECE graduate and IT professional
moving into software development.

**Live:** https://sssfullstack007.github.io/portfolio/

## What this is

A single static page: no frameworks, no build step, no JavaScript. Two files.

| File | Purpose |
|---|---|
| `index.html` | Page structure and content |
| `style.css` | Layout, colours, responsive rules |

## Honest-content rules this page follows

- Every project listed links to a repository that exists.
- Skills are split into "working with now" and "currently learning" so nothing is overstated.
- Contact links are checked before every commit.

## Running locally

Open `index.html` in a browser. That is the whole process.

## Deployment

Served by GitHub Pages from the `main` branch, repository root.
